## ℹ️ 프로젝트 소개
**2025 SID Project**는  
디스플레이 및 관련 기술 연구, 발표자료, 심포지엄 프로그램을 포함하는 프로젝트입니다.  
주요 목적은 다음과 같습니다:
- 연구 결과의 공유
- 학술 네트워킹 강화
- 산업 및 학계 간 협력 촉진
